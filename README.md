1. Project Description

This project is a personal portfolio website developed using Node.js, Express.js, and EJS. The purpose of the website is to introduce myself, provide information about my education and background, showcase projects I have completed, and allow visitors to contact me through a contact form.

The website contains four main pages: Home, About Me, Projects, and Contact Me. Each page has its own content while sharing a consistent navigation bar, header, and footer.

This assignment builds on the personal portfolio website created for Assignment 1. However, this version uses Express.js routing and EJS templates to organize the website and display its content.

2. Website Pages

Home Page

The Home page is the main landing page of the website. It welcomes visitors and briefly introduces the purpose of the portfolio. It also provides an overview of the information visitors can explore throughout the website.

About Me Page

The About Me page introduces me and provides information about my personal interests, education, and background. It includes my profile picture and sections describing my interest in technology, web development, and business. It also highlights some of the skills and programming languages I have learned through my studies at Ontario Tech University.

Projects Page

The Projects page showcases four projects I have worked on during my studies. Each project is displayed in its own card with an icon, title, and description.

The projects included are:

Future Value of Growing Annuity Calculator: An Excel VBA project that calculates the future value of a growing annuity using information such as the first payment, interest rate, growth rate, and number of periods.

Toronto Taxi Fare Calculator: An Excel VBA project that estimates taxi fares based on travel distance, trip duration, and number of passengers.

Python String Information Analyzer: A Python program that analyzes text by counting words, characters, numbers, punctuation, and letter cases. It also includes features for reversing text and changing letter case.

Python Configuration Manager: A Python project that demonstrates working with configuration information and managing settings.

Contact Me Page

The Contact Me page allows visitors to enter their contact information and send a message through a form. The form includes fields for first name, last name, cell number, email address, and message. It also includes a checkbox confirming that the visitor is not a robot, along with Submit and Reset buttons.

The form uses HTML input validation, including required fields, email validation, and a phone number format. When the form is submitted, Express handles the POST request and displays a success message on the Contact Me page. The form demonstrates the submission process but does not send an actual email.

3. Project Structure

The project follows the folder structure generated by Express Generator. The main folders and files are organized as follows:

* bin: Contains the www file, which starts the Express application and handles the server.
* node_modules: Contains the installed Node.js packages and dependencies.
* public: Contains the website’s static files, including images, stylesheets, JavaScript files, Bootstrap files, Font Awesome files, and web fonts.
* routes: Contains index.js, which defines the routes for the Home, About Me, Projects, and Contact Me pages, as well as the Contact Me form submission. It also contains the default users.js route.
* views: Contains the EJS files used to display the website pages. These include index.ejs, about.ejs, projects.ejs, contact.ejs, error.ejs, and layout.ejs.
* app.js: Configures the Express application, sets up the EJS view engine, loads middleware, and connects the routes.
* package.json: Contains the project information, scripts, and dependencies required to run the application.
* package-lock.json: Records the installed package versions and dependency information.

4. Express.js Routing and EJS Templates

Express.js is used to manage the website’s routes and handle requests. The routes are defined in routes/index.js, where each page has its own GET route. These routes use res.render() to display the appropriate EJS page.

The website includes routes for the Home page (/), About Me page (/about), Projects page (/projects), and Contact Me page (/contact). A POST route is also included for handling Contact Me form submissions.

EJS is used as the view engine to create the website’s pages. The layout.ejs file provides a shared layout containing the navigation bar, footer, and common page structure. The individual EJS files contain the content for each page. This approach helps maintain a consistent appearance throughout the website and avoids repeating the same layout code on every page.

The express-ejs-layouts package is used to connect the shared layout with the individual EJS pages.

6. CSS Styling and Responsive Design

Custom CSS is included in public/stylesheets/style.css to control the website’s appearance. It is used to style the page backgrounds, navigation bar, headings, content sections, profile picture, project cards, contact form, and footer.

Bootstrap 5 is used to help make the website responsive across different screen sizes. Bootstrap’s grid system and responsive navigation components are used to organize the content and allow the navigation bar to adjust to smaller screens.

Media queries are also included in the custom CSS to adjust the website’s appearance for tablet and mobile screen sizes.

The website uses gradients, consistent colours, spacing, and typography to maintain a similar design across all four pages.

7. Contact Form Functionality

The Contact Me form uses the POST method to submit information to the /contact route. Express receives the submitted form data and renders the Contact Me page again with a success message.

HTML validation is used to ensure that visitors complete the required fields and enter information in the correct formats. For example, the email field requires a valid email format, and the cell number field follows a specific phone number pattern.

The form is designed to demonstrate form submission and handling through Express.js. It does not send messages to an actual email address.

8. Installing and Running the Project


To run my portfolio website on a local computer, I first made sure that Node.js and npm were installed. I then cloned my GitHub repository using the following command:

git clone https://github.com/Rohaan-666/Assignment2.git

After cloning the repository, I opened the project folder in the terminal and installed all the required dependencies by running:

npm install

Once everything was installed, I started my website using:

npm start

After the server started successfully, I opened my web browser and visited http://localhost:3000 to view my portfolio website locally.

Since I was using Windows PowerShell, I used npm.cmd install and npm.cmd start instead of the regular npm commands because of my system’s execution policy.
